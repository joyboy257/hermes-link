## Format

Each ADR contains:
1. **Title** and **Status** (Proposed/Accepted/Deprecated/Superseded)
2. **Context** — The problem being addressed
3. **Decision** — What was decided
4. **Consequences** — Positive and negative outcomes
5. **Alternatives** — Options considered

Use the template: `adr-XXXX-title.md`
