# Roadmap

> This document outlines the development roadmap for hermes-link.

---

## Version 1.0 — MVP (Q2 2026)

**Goal:** Ship basic marketplace with in-chat install

### Milestone 1.1: Registry Setup (Week 1-2)
- [ ] Set up GitHub registry repository structure
- [ ] Create JSON manifest schema
- [ ] Implement basic validation (schema check)
- [ ] Seed 20 skills from Hermes repo
- [ ] Write README and docs

### Milestone 1.2: Hermes Integration (Week 3-4)
- [ ] Create hermes-link skill for Hermes CLI
- [ ] Implement `/market search` command
- [ ] Implement `/market install` command
- [ ] Implement `/market list` command
- [ ] Implement `/market uninstall` command
- [ ] Error handling and edge cases

### Milestone 1.3: Launch (Week 5)
- [ ] User testing and feedback
- [ ] Bug fixes and polish
- [ ] Public announcement
- [ ] Community engagement

**Success Criteria:**
- 50+ skills in registry
- 100+ installs via marketplace
- 50+ active users

---

## Version 1.5 — Quality System (Q3 2026)

**Goal:** Add quality signals and user accounts

### Features
- [ ] User accounts (GitHub OAuth)
- [ ] Rating system (1-5 stars)
- [ ] Review system with upvoting
- [ ] Quality badges (Featured, Verified, Popular)
- [ ] Search improvements (filters, sorting)
- [ ] Developer dashboard (basic)

**Success Criteria:**
- 200+ skills in registry
- 500+ installs
- 200+ active users
- 10+ premium skills

---

## Version 2.0 — Monetization (Q4 2026)

**Goal:** Enable payments for premium skills

### Features
- [ ] LemonSqueezy integration
- [ ] Premium skill listings
- [ ] Checkout flow (web redirect)
- [ ] Developer payouts
- [ ] Revenue dashboard
- [ ] API for automated publishing

**Success Criteria:**
- 500+ skills in registry
- 2,000+ installs
- 1,000+ active users
- $5,000+/month GMV
